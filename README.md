# Лабораторная работа: Git

## Основные задания (1–8)

Выполнена работа с Git и GitHub:
- Создание и изменение исходного кода программы на Python.
- Последовательное добавление изменений в коммиты.
- Использование `.gitignore`.
- Просмотр истории коммитов и изменений.
- Синхронизация локального репозитория с GitHub.
- Работа с ветками и объединение изменений.

## Задание 9. Работа с историей коммитов

Для демонстрации разных вариантов истории созданы отдельные ветки.

### Схема 9a
Ветки `master-a` и `test-a` указывают на коммит `C35`, полученный при объединении изменений.

### Схема 9b
Ветки `master-b` и `test-b` указывают на линейную историю после `rebase`.

Дополнительные ветки:
- `branch-c3` — история с коммитом `C3`.
- `branch-c4-c5` — линейная история после `rebase`.

## Задание 10. Два изменения одним коммитом

В ветке `history-practice` добавлены два изменения в файл `history.txt`. Оба изменения сохранены одним коммитом `Add two changes in one commit`.

Экспериментальные ветки сохранены на GitHub отдельно от основной ветки `main`.
