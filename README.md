## Пункт 11. Преобразование истории

**Исходная структура:** основная цепочка `C1 → C2 → C5 → C6 → C8-prime → C9-prime` и две дополнительные ветви: `C3 → C4 → C10` и `C8 → C9`.

**Преобразование:** ветка `p11-server` перенесена на `C9-prime` с помощью `rebase`. Коммиты `C3`, `C4` и `C10` получили новые хеши.

**Итоговые ветки:**
- `p11-client` и `p11-master` → `C9-prime`;
- `p11-server` → новый `C10` поверх `C9-prime`;
- `p11-c3` сохраняет исходный `C3`;
- `p11-c8` сохраняет цепочку `C8 → C9`.

**Резервные ветки:** `p11-original`, `p11-original-master`, `p11-original-server` и `p11-original-c8` сохраняют исходные указатели для сравнения и восстановления истории.
